# Sistema visual Veross aplicado às teses

## Tokens oficiais

- Azul profundo: `#060923`
- Dourado: `#AE8A56`
- Dourado claro: `#C9A97A`
- Areia: `#F5EFE2`
- Creme: `#ECD7B4`
- Platina: `#CDCDD0`
- Branco: `#FCFCFC`
- Títulos: League Spartan
- Texto: Mulish
- Dados e marcadores: DM Mono

## Variações

- **Holofote no atleta:** base clara em areia, azul profundo para conteúdo e dourado para ênfase.
- **Holofote no investidor:** base em azul profundo, branco para conteúdo e dourado claro/platina para ênfase.

## Elementos de futebol

As referências são conceituais: linhas de campo, círculo central, área, trajetórias e pontos táticos. Elas aparecem como infraestrutura gráfica, não como ilustração literal.
